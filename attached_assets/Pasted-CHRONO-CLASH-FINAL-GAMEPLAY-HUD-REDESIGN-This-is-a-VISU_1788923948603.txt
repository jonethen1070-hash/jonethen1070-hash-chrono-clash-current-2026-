11. CSS ARCHITECTURE — VERY IMPORTANT
==================================================

The project contains a very large override-heavy aaa-polish.css.

DO NOT simply add another large override block.

Before changing styles:

1. Inspect the existing gameplay HUD DOM.
2. Identify the actual components/classes responsible for:
   - Player HUD
   - VS
   - Timer
   - Top controls
   - Energy
   - Bottom abilities
3. Identify obsolete/redundant CSS rules affecting these components.
4. Consolidate the new HUD styling into a clean, scoped system.
5. Remove or neutralize obsolete conflicting styles where safe.

Avoid:

- !important everywhere
- duplicate selectors
- repeated media queries
- endless override chains
- duplicate HUD components
- absolute positioning hacks that break responsive layouts

The goal is to leave the code cleaner than it was.
