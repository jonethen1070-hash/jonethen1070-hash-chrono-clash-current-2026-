This is CRITICAL.

Gem movement must not depend on inconsistent timer callbacks.

Use elapsed-time based animation.

The movement should remain smooth even when frame times vary slightly.

Do NOT calculate movement as:

“move X amount every frame.”

Instead use elapsed time / normalized progress so the animation remains deterministic.
